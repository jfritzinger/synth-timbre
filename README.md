## Data Format
Loading in a single putative neuron dataset will give you a 'data' variable. This variable is formatted like this:

| Index | Column 1  | Column 2 |
|-------|-----------|----------|
| 1     |           | bin      |
| 2     | rm_con    | rm bin   |
| 3     | mtf_con   | mtf bin  |
| 4     | strf_con  | strf bin |
| 5     | rvf       | schr     |
| 6     | st 43 con | st 43    |
| 7     | st 63 con | st 63    |
| 8     | st 73 con | st 73    |
| 9     | st 83 con | st 83    |
| 10    |           | st 43 100Hz |
| 11    |           | st 63 100Hz |
| 12    |           | st 83 100Hz |
| 13    |           | Oboe        |
| 14    |           | Bassoon     |
| 15    |           | Other nt    |
